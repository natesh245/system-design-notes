# 🧠 How LLMs Work: Core Mechanics & High-Level Architecture

To build effective AI agents, you need a clear mental model of how an LLM processes text and generates responses.

---

## 🔄 The 5-Step Pipeline of an LLM Call

```
User Input Text ("Explain async I/O")
         │
         ▼
 1. Tokenization  (Text ──► Token IDs)
         │
         ▼
 2. Embedding & Positioning  (Token IDs ──► High-Dimensional Vectors)
         │
         ▼
 3. Transformer Decoder  (Multi-Head Self-Attention + Feed-Forward Layers)
         │
         ▼
 4. Next-Token Sampling  (Logits ──► Softmax Probabilities ──► Selected Token)
         │
         ▼
 5. Autoregressive Loop  (Append Token to Prompt & Repeat until Stop Token)
```

---

## 1. Tokenization (Text to Numbers)
- Models cannot process raw strings; text is split into subword chunks called **Tokens** using algorithms like BPE (Byte Pair Encoding).
- Example: `"Unbelievable"` $\rightarrow$ `["Un", "believ", "able"]` $\rightarrow$ `[3421, 8912, 412]`.
- Rule of thumb: ~1 token $\approx$ 0.75 English words (or ~4 characters).

---

## 2. Embeddings & Positional Encodings
- Each Token ID is mapped to a dense vector (e.g., 4096 dimensions) representing its initial semantic meaning.
- **Positional Encoding** (e.g., RoPE - Rotary Position Embedding) is injected into vectors so the model understands the relative order of words in the sentence.

---

## 3. The Transformer Decoder Stack
- Modern LLMs (GPT-4, Claude 3.5, Llama 3, Gemini) use **Decoder-Only Transformer** architectures.
- **Multi-Head Self-Attention**: Allows every token to dynamically "attend to" and weigh its relationship with all preceding tokens.
- **Feed-Forward Layers**: Transform the attended representations across dozens of deep layers to build complex reasoning.

---

## 4. Next-Token Prediction & Sampling
- The output layer generates a raw score (**logit**) for every word in the model's vocabulary (e.g., 128,000 possible tokens).
- A **Softmax** function turns logits into probabilities summing to 1.0.
- **Sampling Controls**:
  - **Temperature**: Controls randomness (lower = deterministic/focused, higher = creative).
  - **Top-P (Nucleus Sampling)**: Selects from the top cumulative probability pool.
  - **Greedy Decoding**: Always picks the single highest-probability token.

---

## 5. Post-Training Alignment (Base Model ──► Assistant)
1. **Pre-training**: Model reads trillions of tokens from the internet to master grammar, facts, and prediction (Base Model).
2. **Supervised Fine-Tuning (SFT)**: Trained on thousands of high-quality `(User Instruction, Ideal Answer)` dialog pairs.
3. **RLHF / DPO**: Aligned via Reinforcement Learning from Human Feedback or Direct Preference Optimization to adhere to safety, helpfulness, and system prompts.
